# Carpeta de Imágenes

Coloca aquí tus propias fotografías nocturnas en formato `.jpg`, `.webp` o `.png`.

### Consejos de Optimización para la Web:
1. **Dimensiones**: Con un ancho de 1600px a 2000px es más que suficiente para verse nítido en pantallas 4K y Retina sin pesar demasiado.
2. **Peso**: Intenta que cada foto pese entre 200 KB y 600 KB para que tu portafolio cargue instantáneamente. Herramientas gratuitas como [Squoosh.app](https://squoosh.app) o TinyJPG son excelentes para esto.
3. **Vincular en la galería**: Abre el archivo `js/gallery-data.js` y apunta la propiedad `src` y `thumb` a tu imagen (por ejemplo: `images/mi-foto.jpg`).
